# Job Application Tracker — Dawit Abdisa

Everything about my job search in one place, so any new session can pick up where the last one stopped.

| File | What it holds |
|---|---|
| [`applications.csv`](applications.csv) | Every application: company, role, status, date, next step, links |
| [`profile.md`](profile.md) | Who I am, my CV summary, and the standard answers I give on application forms |
| [`search-log.md`](search-log.md) | Which websites were searched, what was found, and which platforms I can't use (and why) |
| [`next-steps.md`](next-steps.md) | Open to-dos and recommendations |

## For a new session (human or AI)

1. Read `profile.md` for background and form answers.
2. Read `applications.csv` to see what has already been applied to — don't apply twice.
3. Read `search-log.md` before searching, to skip sites already checked or not open to me.
4. After any new application or status change, update `applications.csv` and add a dated line to `search-log.md`.

## Status values

`Applied` · `Assessment` · `Interview` · `Offer` · `Rejected` · `Withdrawn`
